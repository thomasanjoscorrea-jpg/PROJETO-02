# PROJETO-02

Modelo de cardápio online para uma pizzaria e petiscaria, feito em HTML, CSS e JavaScript puros.

## Arquivos
- `index.html`: o site (desenho e funcionamento). Normalmente **não precisa mexer**.
- `cardapio.js`: **dados da loja e cardápio** (preços, itens, fotos, horário, WhatsApp). É aqui que se edita.
- `imagens/`: fotos dos itens e o logo.
- `COMO-EDITAR.md`: passo a passo, em português simples, para trocar preço, incluir item, trocar foto etc.
- `CREDITOS.md`: origem das fotos.

## Para ver o site
Abra o `index.html` no navegador (ou publique a pasta em Cloudflare Pages, Netlify ou GitHub Pages).

## Antes de usar de verdade
1. Trocar `WHATSAPP_NUMERO` em `cardapio.js` pelo número da loja.
2. Confirmar preços e tirar `exemplo: true` dos itens confirmados.
3. Trocar as fotos de banco de imagens pelas fotos reais, se houver.
4. Esvaziar `AVISO_DEMO` para tirar a faixa de proposta.
