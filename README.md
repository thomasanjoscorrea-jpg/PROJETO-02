# PROJETO-02

Modelo de apresentação de cardápio online para uma pizzaria e petiscaria, feito em HTML, CSS e JavaScript puros.

- `index.html`: o site completo (abra no navegador).
- Os dados da loja, o cardápio e o número do WhatsApp ficam no começo do `<script>`, comentados.
- Itens marcados com `exemplo: true` têm preço de exemplo e mostram a etiqueta "Exemplo" no site.
